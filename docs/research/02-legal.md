# 02. 法務調査（日本法・海外法・プラットフォーム規約）

調査日: 2026-10-04。Sonnet 5.5 のサブエージェント2体が調査し、Opus 5.5 が整理しました。条文は e-Gov で現行版を確認しています。

> 本書は法的助言ではありません。「確定」としたのは、条文・公的文書から直接導ける結論です。無償のゲーム内通貨について、それを直接判断した判例や政府答弁は見つかっていません。

## 結論（日本法）

**次の5つのガードレールを守る限り、本アプリは日本法上、賭博罪・風営法・資金決済法・景品表示法・改正ギャンブル等依存症対策基本法のいずれにも該当しない構造です。**

1. **購入しない**: チップの購入手段を一切設けない。課金・広告視聴報酬・寄付連動の付与もない。
2. **換金しない**: チップを現金・景品・ポイント・暗号資産・割引・外部特典と交換する経路を設けない。ランキング上位者への賞品も出さない。
3. **譲渡しない**: プレイヤー間の送金・ギフト・取引機能を設けない。（当初は「プライベート卓・招待卓も作らない」としていたが、2026-10-08 にさつきがプライベート卓の導入を決めた。§5 の追記を参照）
4. **収益化しない**: 広告・投げ銭・スポンサー・アフィリエイトを置かない。賭博場開張図利の「利益を図る」要件を欠く状態を保つ。
5. **誘導しない**: 実在のオンラインカジノや実マネーポーカーサイトへのリンク・名称紹介・「本番で稼ごう」のような表現を一切載せない。

**このどれか1つでも崩す場合（課金、賞品、チップ交換、広告など）は、全論点を再検討する必要があり、弁護士への確認が前提になります。**

| 論点 | 結論 | 確度 |
|---|---|---|
| 刑法185条・186条 賭博罪 | 構成要件の「財物・財産上の利益の得喪」を欠くため不成立 | 条文解釈としては確定。無償通貨そのものを判断した判例はない |
| 風営法2条1項5号・23条 | 5号営業は「店舗その他これに類する区画された施設」が要件のため、ウェブアプリは対象外 | 確定 |
| 景品表示法 | 賞品がないので問題は生じない | 確定 |
| 資金決済法（前払式支払手段） | 「対価を得て発行される」ものではないので該当しない | 確定 |
| ギャンブル等依存症対策基本法 9条の2（2025年改正） | 本アプリは「違法オンラインギャンブル等」ではない。外部サイトへのリンクだけが危険 | 確定（条文から） |
| 商標「SPIN & GO」 | **PokerStars側の登録商標**。アプリ名に使ってはいけない | 確定（WIPOのデータベースで確認）。J-PlatPatでの最終確認を推奨 |
| チップ譲渡・RMT | 最大のリスク源。市場価値が付くと賭博罪の前提が崩れる | 設計で防ぐ |
| 年齢 | 法律上の年齢制限はない。運用上は18歳以上を推奨 | 設計論 |

## 1. 賭博罪（刑法185条・186条）
- **条文**（https://laws.e-gov.go.jp/law/140AC0000000045）
  - 185条: 賭博をした者は50万円以下の罰金または科料。ただし「一時の娯楽に供する物」を賭けたにとどまるときは罰しない。
  - 186条: 常習賭博、賭博場開張等図利。
- **賭博の定義**: 偶然の勝敗によって、財物や財産上の利益の得喪を争うこと。ポーカーのように技能の要素があっても、偶然性が残れば該当し得る。
- **無償・換金不可・譲渡不可のチップ**: 財物にも財産上の利益にも当たらないため、構成要件を欠く。弁護士の解説では「有償ポイントは財産上の利益に当たり得る」「RMTで換金できる場合は財産上の利益と評価されやすい」とされている。
  - https://nao-lawoffice.jp/venture-startup/platform/online-game2.php
  - https://jitsumu-guide.com/amusement-casino-legality-guide-2026/
- **「一時の娯楽に供する物」の例外は主たる論拠にしない**: 判例では、金銭はいくら少額でも該当しないとされている（最判昭和23年10月7日）。本アプリの主たる論拠は「チップに財産的価値がない」ことに置く。
- **186条2項（賭博場開張等図利）**: 「利益を図る」目的が要件。広告も課金もない本アプリでは、リスクは極小。

## 2. 風営法・アミューズメントポーカー
- 店舗型のアミューズメントポーカーは、風営法2条1項5号の許可（ゲームセンター等営業）を受けて営業している。条件は、チップが店内だけで使われ、現金や景品と交換されないこと（23条2項・3項）。
- **5号営業は「店舗その他これに類する区画された施設」で客に遊技をさせる営業**であり、オンラインの無料アプリは対象外。
  - 解釈運用基準（令和8年7月1日）: https://www.npa.go.jp/laws/notification/seian/hoan/hoantsutatu2/R080701kaisiyaku.pdf
  - 風営法: https://laws.e-gov.go.jp/law/323AC0000000122
- **2025年12月の摘発**: 警視庁がアミューズメントカジノ80店に立入りし、48店で違反を確認した。店舗間で使える「ウェブコイン」が、賞品交換やチップの持ち出しの経路になっていた。
  - **教訓**: 実店舗との提携、チップと店舗特典の連動は絶対に行わない。

## 3. 景品表示法
- 景品類は「取引に付随して」提供されるもの（2条3項）。無料のアプリは取引に付随しないため、賞品を出してもオープン懸賞扱いになる。
- ただし、**チップ残高（ランキング）と賞品を連動させると、チップが「賞品の獲得権」という価値を持ち、賭博罪の前提が崩れる。** 賞品を出すことは推奨しない。
- 参考（消費者庁FAQ）: https://www.caa.go.jp/policies/policy/representation/fair_labeling/faq/premium/introduction

## 4. 資金決済法
- 前払式支払手段は「対価を得て発行される」もの（3条1項）。無償でしか発行しないチップは該当しない。
  - 資金決済法: https://laws.e-gov.go.jp/law/421AC0000000059
  - 金融庁事務ガイドライン: https://www.fsa.go.jp/common/law/guide/kaisya/05.pdf

## 5. 譲渡・RMT・チップダンピング（最大のリスク源）
- RMTそのものを処罰する法令はない。しかし、チップに市場価値が生じれば、プレイヤーは賭博罪に問われ得る。運営者が黙認すれば、賭博幇助や開張図利の助長に問われるおそれがある。
- **設計での対策**
  - 送金・ギフト機能を作らない。
  - マッチングはランダムにし、相手を選べないようにする。
  - Googleアカウント1つにつきアカウント1つ。
  - フリーロールの回数制限はアカウント単位で管理する。
- **規約での対策**: RMT、アカウント売買、意図的に負けてチップを移すこと（ダンピング）、多重アカウントを禁止する。運営者がチップを調整・没収し、アカウントを停止できる条項を置く。
- **運用での対策**: 同じ組み合わせの対戦が不自然に多い場合などを、余力があれば検知する。フリマやSNSにRMTの出品があれば通報する。
- **2026-10-08 追記（プライベート卓）**: さつきの判断で、部屋番号を共有した相手と同じ卓に着けるプライベート卓を導入した（残高は PLAY と同じく増減する）。上の「相手を選べないようにする」は崩れ、知り合い同士でチップを移すことは技術的に容易になる。残る対策は規約（ダンピングの禁止、運営者によるチップの修正・利用制限、参加者間の取り決め・やり取りについて運営者は責任を負わない旨）と、`games.state.meta.room`・`rooms` に残る記録による事後の確認。なお、免責条項は利用者どうしの行為の刑事上の評価を変えるものではなく、消費者契約法 8 条により運営者の故意・重過失まで免責する条項は無効になるため、規約の免責は「故意または重大な過失がある場合を除き」の形にしている。
- **2026-10-08 追記（チャット）**: 卓のチャットは PRIVATE の卓だけに置いた。ランダムにマッチする PLAY・FREEROLL の卓にチャットがあると、知らない相手にチップの受け渡し（RMT）を持ちかける場になりやすいため。発言はサーバーに残し（卓と一緒に 7 日で削除）、規約で受け渡しの持ちかけを禁じている。

## 6. 2025年のギャンブル等依存症対策基本法改正（令和7年法律第76号、2025年9月25日施行）
- **9条の2が禁止しているのは2つ**
  - 違法オンラインギャンブル等のサイトを、不特定の者に「提示」すること
  - そこへ「誘導する情報」を発信すること
- 本則に罰則はない。
  - 条文: https://laws.e-gov.go.jp/law/430AC1000000074
- **総務省ガイドラインの「誘導情報」の例**（https://www.soumu.go.jp/main_content/001030702.pdf）
  - 違法サイトのURLを載せること
  - 実在するサイト名と「無料」「ランキング」「入金不要ボーナス」などの言葉を一緒に載せること
  - 無料版サイトから違法サイトへ誘導すること
  - 「違法なので勧めない」と書いても、全体として誘導と認められれば該当する
- **警察庁は「無料版でもオンラインカジノは利用しないように」と注意喚起している。** 本アプリが実在のオンラインポーカーの「無料版」や「入口」と見られないようにすることが重要。
  - https://www.npa.go.jp/bureau/safetylife/hoan/onlinecasino/onlinecasino.html
- **対応**
  - PokerStars・GGPokerなどの実在サイト名をアプリ内に一切書かない。
  - 「本番」「実戦」「稼ぐ」といった言葉を使わない。
  - 依存症の相談窓口へのリンクを置く。

## 8. 年齢
- 法律上の年齢制限はない。ただし推奨は次のとおり。
  - 利用規約で「18歳以上」を対象にする（最低でも13歳以上＋保護者の同意）。
  - 初回ログイン時に年齢を自己申告してもらう。
- 個人情報保護法の令和8年改正（令和8年法律第56号）で、16歳未満については法定代理人の同意が原則になる。施行日は未定。

## 9. 海外法・プラットフォーム規約

| 論点 | 結論 |
|---|---|
| 米国のソーシャルカジノ訴訟（Kater v. Churchill Downs 等） | 争点はすべて「チップを購入できた」こと。完全無料なら典型的な請求は成り立たない。**ただしワシントン州だけは例外**で、州法は「遊戯の特権の延長」も thing of value に含める（RCW 9.46.0285）。州の賭博委員会（WSGC）は、仮想通貨で賭けて仮想通貨を得るゲームも違法の可能性が高いという立場。2026年7月には州司法長官がソーシャルカジノ各社を提訴している（購入型が対象） |
| 米国のSweepstakes禁止法（NY・CA など） | 対象は「二重通貨＋現金賞品」。本アプリは対象外。Sweeps・Gold Coin・Redeem・Cash Out などの用語を使わない |
| 英国 | 賭博法は「金銭またはその価値」が前提。換金できないチップは対象外 |
| 韓国・中国・豪州 | 韓国はポーカーを実金なしでも19禁と分類する傾向があり、等級分類なしの配布には罰則がある。中国はポーカーアプリを禁止している。豪州は simulated gambling を R18+ に分類する。**日本語のみで提供し、これらの国を対象にしない** |
| ルートボックス規制 | 対象は「購入するランダム報酬」なので、本アプリは対象外。確率表は任意で公開する |
| Google Play / App Store | 当面はWeb（PWA）のみ。ストアに配信する場合は simulated gambling の申告が必要で、18+になる見込み。iOSでは Sign in with Apple とアカウント削除機能が必須 |
| Google OAuth | 基本スコープ（openid/email/profile）なら審査は不要（ブランド確認のみ）。APIs利用規約4aは違法なオンライン賭博の助長を禁止しているが、本アプリは該当しない。**プライバシーポリシー・利用規約・ホームページのURLが必須**。同意画面に casino・betting・cash などの語を使わない |
| Cloudflare / Neon の利用規約 | プレイマネーのゲームを禁止する条項はない |
| 個人情報 | 日本の個人情報保護法が適用される（個人運営でも除外されない）。外国にあるサーバー（Neon・Cloudflare）を利用する場合は、その国名をプライバシーポリシーに書く。GDPRは「EU向けに提供」していなければ原則適用外。**プレイヤー間チャットを作らなければ、電気通信事業の届出は不要の見込み** |

主な出典:
- WSGC: https://wsgc.wa.gov/regarding-virtual-casinos
- ワシントン州法: https://app.leg.wa.gov/rcw/default.aspx?cite=9.46.0285
- Google APIs 利用規約: https://developers.google.com/terms
- Google OAuth のポリシー遵守: https://developers.google.com/identity/protocols/oauth2/production-readiness/policy-compliance
- Apple 年齢レーティング: https://developer.apple.com/help/app-store-connect/reference/age-ratings-values-and-definitions
- PPC Q&A（外国のクラウドを利用する場合）: https://www.ppc.go.jp/all_faq_index/faq1-q7-53/

### 海外リスクへの推奨対応: **日本国内からのアクセスに限定する**
Cloudflare Pages Functions のミドルウェア（`functions/_middleware.js`）で `request.cf.country !== 'JP'` を判定し、ブロックページを返す。
- これだけで、ワシントン州・韓国・中国・豪州・GDPRの論点をまとめて実質的に消せる。
- VPNで回避される分は、利用規約の「日本国内居住者向け」で対処する。
- 補足: Neon の Data API と Function は Neon のドメインに直接届くため、地域制限はかからない。ただし、サービスとしてのUIを提供しないことが目的なので、これで十分。

## 10. 利用規約・表示に入れる文言（チェックリスト）
1. 無料の娯楽であること。金銭・賞品・ポイント・暗号資産その他の財産的価値を賭けるものではない。
2. チップはサービス内でのみ使える仮想の遊技媒体で、財産的価値はない。何とも交換できない。
3. チップは購入できない。無償配布のみ。
4. チップ・アカウントの譲渡・貸与・売買・担保提供・相続を禁止する。
5. ダンピング、共謀、多重アカウント、Bot・自動化、バグの悪用を禁止する。
6. RMT（現実の金銭との交換）と、その仲介・勧誘・広告を禁止する。
7. 運営者がチップの調整・削除やアカウント停止をできること（ただし「法令で許される範囲で」責任を制限する。消費者契約法8条に注意）。
8. サービスの変更・終了時にチップは消滅し、補償しない。
9. 現実のオンラインカジノや実マネーのポーカーとは無関係であること。日本国内から金銭を賭けることは犯罪である旨の注意書き。
10. 対象年齢（18歳以上）。
11. ランキングは娯楽目的で、賞品・特典は一切ないこと。
12. 名称・ロゴは他社の商標と無関係であること（他社名を出す場合は「提携・承認関係なし」と書く）。
13. 個人情報の取扱い（プライバシーポリシーへのリンク）。
14. 免責、準拠法（日本法）、管轄裁判所。
15. 規約変更の条項（民法548条の4）。
16. 日本国内居住者向けのサービスであること。

**常に表示する文言（フッター・初回起動時）の例**:
「本アプリは無料の娯楽ゲームです。チップは無償配布のみで、購入・換金・譲渡・景品交換はできません。実際のお金や賞品を賭けることはできません。18歳以上の方を対象としています。」
- 「賭博ではありません」と法的評価を断定するより、事実を列挙する書き方の方が安全。
- 依存症の相談窓口へのリンクも置く（窓口の情報は公開前に最新版を確認する）。

## 11. 専門家（弁護士・弁理士）への確認を推奨する点
1. アプリ名の商標クリアランス（J-PlatPat）。
2. 将来、賞品・課金・広告を入れる場合（全論点の再レビュー）。
3. 海外アクセスを制限しない場合の、ワシントン州と韓国のリスク。
4. プライバシーポリシーの文面（外国にある第三者への提供の扱い）。
