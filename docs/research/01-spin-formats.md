# 01. 各社ジャックポットSNG（Spin&Go系）仕様調査

調査日: 2026-10-04。Sonnet 5.5 のサブエージェント2体で調査し、Opus 5.5 が整理した。

- 公式サイトの多くは地域制限（403/451）で直接は取得できなかった。そのため、数値の多くは第三者メディアや運営の告知記事から取っている。
- 確率表は「合計が100%になるか」「期待倍率÷3がレーキ控除後の還元率と一致するか」を自分たちで検算した。一致したものは【確定】とした。

## 1. 共通の構造（全社共通の事実）

| 項目 | 内容 |
|---|---|
| 人数 | 3人（888 BLASTは2019年以前は4人。PokerStars MaxやGGの6-maxは派生形式） |
| ゲーム | NLHE ハイパーターボ。開始ブラインドは 10/20、アンテなし（888・HexaProはアンテあり） |
| 初期スタック | 500（25bb）が基本。現行の主流は「低倍率ほど浅く速く、高倍率ほど深く遅く」 |
| 抽選 | 3人が揃った瞬間にサーバーが倍率を抽選し、ホイール（ルーレット）演出で表示してから第1ハンド |
| 賞金 | 賞金プール = 倍率 × バイイン。低倍率は1位総取り。高倍率（10x/25x以上）は2位・3位にも分配する社が多い |
| 還元率 | **還元率（RTP）= E[倍率] ÷ 3**。全社でレーキ5〜10%（E[倍率] ≈ 2.7〜2.85） |
| 期待値の内訳 | 期待値の約8割は2x/3xが占める。ジャックポットの寄与は1〜3%にすぎないが、分散のほとんどはジャックポットが生む |
| 試合時間 | 平均3〜7分 |
| ディール | 不可（WSOPは明記） |

## 5. UX の実例とベストプラクティス

- **ホイール演出は5〜10秒。** 高倍率ほど演出を長くする。何十回も繰り返すゲームなので、短縮・スキップの設定を設ける。
- **抽選はサーバーで行い、結果をホイールで見せる。** 「ニアミス」を水増しする演出は操作的な設計なので採用しない。
- **確率表を常に公開する。** Winamax・888・Unibet・WPN は全確率表を公式に掲載している。
- **x2の失望を和らげる。** 低倍率ほどゲームを速くする設計が全社共通（試合時間を短くすることで、x2を早く通過させる）。
- **連続プレイの流れを止めない。** 終了後すぐ再参加できるボタンを用意する（Winamax には自動再エントリー機能がある）。

## 6. 戦略的特徴（UI・Bot設計の参考）
- 3人卓では3ハンド中2ハンドでブラインドを払うため、待ちの戦略は成立しない。総取りなのでICMはない。
- BTNのミニレイズは約40%、BBのディフェンスは65〜70%。10bb以下はプッシュ／フォールド。
