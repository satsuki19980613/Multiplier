2. 取得する情報

本サービスでは、次の情報を取得します。

(1) Google アカウントでのログインにより取得する情報

本サービスは、認証基盤として Neon Auth（Neon の認証機能）を利用し、Google アカウントによるログインを行います。ログインの際に、次の情報が Neon Auth のデータベースに保存されます。

  • Google アカウントの識別子（ユーザーID）
  • メールアドレス
  • 氏名（Google アカウントの表示名）
  • プロフィール画像のURL（Google から提供される場合）
  • ログインのセッションに関する情報（ログインの有効期限、接続元に関する情報など）

運営者は、本サービスのゲーム画面でこれらの情報を他のユーザーに表示しません。

(2) 本サービスが保存する情報

  • ニックネーム（ユーザーが設定するもの。ランキングに表示されます。）
  • チップ数
  • フリーロールの利用回数
  • ゲームの進行データ（手札、ベット、結果など。ゲームの終了後7日で削除します。）
  • 殿堂入りの記録（シーズン上位者のニックネームとチップ数。公開されます。）

(3) アクセスログ

本サービスの配信には Cloudflare, Inc.（以下「Cloudflare」といいます。）のサービスを利用しており、Cloudflare は、アクセスに伴って IP アドレス、リクエストの日時、アクセスしたURL、ブラウザの種類などの情報を取得します。本サービスは、日本国内からの利用に限定するため、IP アドレスから推定される国の情報を判定に利用します。

(4) ブラウザに保存される情報

本サービスは、お使いのブラウザの localStorage に、画面のテーマ（ライト／ダーク）の設定、および18歳以上であることの確認の記録を保存します。これらはお使いの端末内に保存され、ブラウザの設定から削除できます。

(5) 利用しない情報

本サービスは、外部の解析サービス、広告配信サービス、トラッキングのための SDK・Cookie を利用していません。位置情報、連絡先、端末内のファイルにもアクセスしません。

3. 利用目的

運営者は、取得した情報を、次の目的の範囲で利用します。

  1. ログインとアカウントの識別、本人による利用の確認
  2. ゲームの提供（対戦、チップ数の管理、フリーロールの回数管理、ランキングと殿堂入りの表示）
  3. 不正利用（多重アカウント、チップダンピング、自動操作、不具合の悪用など）の防止・検知と、利用規約に基づく対応
  4. 本サービスの安全の確保、障害の調査、運営
  5. 日本国内からの利用に限定するための判定
  6. お問い合わせへの対応、利用規約・本ポリシーの変更の通知

運営者は、利用目的を変更する場合、変更前の目的と関連性を有すると合理的に認められる範囲を超えて変更しません。

4. 第三者提供

運営者は、次の場合を除き、ユーザーの個人データを第三者に提供しません。

  • ユーザーの同意がある場合
  • 法令に基づく場合
  • 人の生命、身体または財産の保護のために必要で、本人の同意を得ることが困難な場合
  • その他、個人情報保護法が認める場合

なお、ランキングと殿堂入りには、ニックネームとチップ数のみを表示します。メールアドレスや氏名は表示しません。

6. 安全管理措置

運営者は、個人データの漏えい、滅失または毀損の防止その他の安全管理のため、次の措置を講じます。

  • 通信の暗号化（HTTPS）
  • データベース・サーバーへのアクセス権限の制限、認証情報（秘密鍵、接続文字列等）の適切な管理
  • ゲームの進行データの定期的な削除（ゲームの終了後7日）
  • 取り扱う個人データを、本サービスの提供に必要な範囲に限定すること
  • 個人情報の取扱いに関する運営者自身のルールの整備と見直し

9. アカウントの削除方法

アカウントと、これに関連するデータ（ニックネーム、チップ数、フリーロールの利用回数、Neon Auth に保存されたメールアドレス・氏名など）の削除を希望する場合は、上記の窓口（【連絡先】）までご依頼ください。運営者が本人確認を行ったうえで、削除します。今後、本サービス内で削除の操作ができるよう、機能を追加する予定です。

アカウントを削除すると、チップ数は元に戻せません。なお、殿堂入りの記録は、ニックネームの削除または匿名化により対応します。

10. Google ユーザーデータの取扱い

本サービスによる Google から受け取った情報の使用および他のアプリへの転送は、限定的使用の要件を含め、Google API サービスのユーザーデータに関するポリシー（Google API Services User Data Policy）に準拠します。

  • 本サービスが Google から取得するのは、ログインに必要な基本的な情報（識別子、メールアドレス、氏名、プロフィール画像のURL）のみです。
  • これらの情報は、ログインとアカウントの識別、本サービスの提供のためにのみ利用します。
  • 広告の配信、第三者への販売・提供には利用しません。

11. Cookie などについて

本サービスは、ログイン状態を保つために、認証に必要な Cookie またはブラウザのストレージを利用することがあります。広告やトラッキングを目的とした Cookie は利用しません。ブラウザの設定で Cookie を無効にすると、ログインできない場合があります。

12. 未成年の方について

本サービスは、18歳以上の方を対象としています。18歳未満の方の個人情報を、意図して取得することはありません。
